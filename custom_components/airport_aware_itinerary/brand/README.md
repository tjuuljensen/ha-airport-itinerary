# Brand artwork

The HACS/Home Assistant brand icons preserve the approved canvas layout. `icon.svg` and `dark_icon.svg` are editable SVG source files with the artwork embedded as an image object. The original transparent canvas export is retained at `source/canvas_source.png`.

PNG exports are provided at 256x256 (`icon.png`, `dark_icon.png`) and 512x512 (`icon@2x.png`, `dark_icon@2x.png`). The dark variant keeps the composition and brightens the plane, ring, and clock hand for contrast on dark backgrounds.
